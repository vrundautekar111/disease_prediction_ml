Disease Prediction Using Machine Learning

The Disease Prediction Using Machine Learning project is a Python-based application that uses a Random Forest classification algorithm to analyze selected symptoms and generate predicted symptom-pattern categories. It features an interactive web dashboard built with Streamlit and a modern dark-themed user interface.

Features

Symptom selection and analysis

Machine learning classification using Random Forest

Top three predicted class scores displayed in a bar chart

Interactive dashboard with a dark theme

Synthetic dataset generation and model training

Model evaluation using a held-out test dataset

Simple and user-friendly interface

Technologies Used

Python

Pandas

Scikit-learn

Streamlit

Joblib

Machine Learning

Git and GitHub

Project Workflow

Generate synthetic symptom data.

Preprocess symptom features into numerical values.

Train a Random Forest classification model.

Evaluate the model on held-out synthetic examples.

Select symptoms through the Streamlit dashboard.

Display the predicted demo category and model scores.

Objective

The objective of this project is to demonstrate how machine learning classification, data processing, model training, and web application development can be combined into an interactive application.

Disclaimer

This project is intended for educational and portfolio demonstration purposes only. It uses synthetic data and is not medically validated. Predictions are not diagnoses and must not be used to make medical decisions.
